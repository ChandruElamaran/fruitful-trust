# Fruitful Trust website

A simple static website (HTML, CSS, JavaScript). No installation needed.

## How to open
Double-click `index.html`.

## Folder layout
- index.html     - all the page content
- css/style.css  - colours, fonts and layout
- js/script.js   - mobile menu and contact form
- images/        - your photos (see images/README.txt)
- videos/        - your videos (see videos/README.txt)

## What to change first
1. Numbers in the "numbers" strip
2. Bank details, 80G number, address, phone, email in index.html
3. Email address in js/script.js
4. Add your photos and videos

## Put it online for free
Upload the whole folder to Netlify Drop, GitHub Pages or Cloudflare Pages.
